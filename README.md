# skills

renjinxi 的个人 agent skills 收纳仓，供 [skills CLI](https://www.npmjs.com/package/skills) 安装：

```bash
npx skills add renjinxi/skills -g
```

## 收录

| skill | 说明 |
|-------|------|
| `zoom-out` | 让 agent 上升一层抽象，用项目领域词汇画出相关模块与调用方的地图 |
| `setup-project` | 从私人标准模板创建全新的 GitHub 私有仓库和本地 clone；已有仓库保持原样 |
| `clip` | 把指定内容（命令、代码、上一条回答、文件内容等）复制到系统剪贴板 |
| `erp-implement-spec` | 在 erp-main 多仓 workspace 里按 /implement-spec 实现整份 spec，内置分支、子仓 worktree、推送、收尾和测试约定（依赖 mattpocock `implement-spec`） |
